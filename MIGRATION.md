# macOS App Migration Guide

A step-by-step guide to migrating all apps from your old Mac to a new one using the Brewfile generated by this repo.

---

## On your old Mac — before you migrate

### 1. Generate a fresh Brewfile snapshot

```bash
cd ~/brewfile-generator
./generate-brewfile.sh ~/brewfile-generator/Brewfile
```

### 2. Commit and push to GitHub

```bash
git add Brewfile && git commit -m "chore: pre-migration snapshot $(date +%Y-%m-%d)" && git push
```

---

## On your new Mac — setting up

### 3. Install Homebrew

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### 4. Clone your Brewfile repo

```bash
git clone https://github.com/rbird/brewfile-generator ~/brewfile-generator
```

### 5. Install `mas` and sign into the App Store

```bash
brew install mas
```

Then open the **App Store** app and sign in — `mas` requires an active session to install apps.

### 6. Run the restore

```bash
brew bundle install --file=~/brewfile-generator/Brewfile
```

This installs all Homebrew taps, formulae, casks, and Mac App Store apps automatically.
Expect this to take 20–60 minutes depending on how many apps you have.

---

## Manual steps after `brew bundle` completes

### 7. Reinstall Setapp apps

Print your Setapp checklist:

```bash
grep "^# setapp" ~/brewfile-generator/Brewfile | sed 's/# setapp "//;s/"//'
```

Open the **Setapp** desktop app, search for each app by name, and install. All apps are
included in your subscription — no individual purchases needed.

### 8. Reinstall manually installed apps

Print your manual checklist:

```bash
grep "^# manual" ~/brewfile-generator/Brewfile | sed 's/# manual "//;s/"//'
```

For each app:

1. Check if it's now available via Homebrew (`brew search <name>`) or the App Store —
   install methods may have changed since you first got it.
2. If not, download the installer directly from the vendor's website.
3. Re-enter any license keys — check your email or password manager.

---

## Keep your Brewfile current

Re-run `./generate-brewfile.sh` any time you install something new, or activate the
weekly Launch Agent described in the [README](README.md#automating-with-a-launch-agent-recommended)
to keep it updated automatically.
